## Atomic settlement contract
The previous payment path could persist `settled` and then persist the entitlement receipt as a second store operation. A crash between those writes could leave a settled operation without its recoverable receipt.

TDD RED evidence:

The `PaymentStateStore` contract now exposes `confirmSettlement(operationId, receipt)`. The Nano payment gate delegates confirmed settlement to that single store operation, so a production backend must persist the `settling -> settled` transition and bounded receipt atomically.

The D1 design enforces:
- unique payment identity;
- unique operation ID;
- atomic first-claim ownership through a database uniqueness constraint plus read-back;
- request-rebinding conflict detection;
- conditional SQL compare-and-set state transitions;
- one conditional SQL write for confirmed settlement state plus receipt;
- receipt validation on both write and read;
- fail-closed behavior for unresolved claim conflicts or invalid persisted state;
- no automatic retries around ambiguous settlement writes.

## Durability evidence
The local D1 contract harness uses Node SQLite with the production migration and the same `prepare/bind/run/first` statement shape expected from the Cloudflare D1 binding.

Tests prove:
- concurrent claims produce one owner and one idempotent existing result;
- one payment identity cannot be rebound to another protected request;
- stale CAS transitions cannot both win;
- settlement confirmation fails outside `settling`;
- `settling -> settled` plus receipt persistence is one conditional write;
- state and receipt survive closing and reopening the same database;
- a reconstructed store recovers the confirmed entitlement;
- production gate composition accepts the D1 store and continues to reject `MemoryPaymentStateStore`.

A Node strip-only TypeScript incompatibility was encountered in the test harness because constructor parameter properties are not supported by that runtime mode. Only the harness syntax was changed to ordinary class fields; the production D1 adapter did not change.
